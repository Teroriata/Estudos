# Compilação e Execução

Para compilar o projeto, abra o terminal na pasta onde estão os arquivos `.java` e execute:

```powershell
javac *.java
```

Se a compilação for concluída sem erros, execute o programa com:

```powershell
java Main
```

O arquivo `vendas.csv` deve estar localizado na mesma pasta do projeto.

## Exemplo de execução

```powershell
PS C:\caminho\PipesAndFilters> javac *.java
PS C:\caminho\PipesAndFilters> java Main
```
